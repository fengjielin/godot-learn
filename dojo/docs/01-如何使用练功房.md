## 1. 跑起来

```powershell
cd E:\Code\GameDev\Godot\dojo

# 改完 C# 必须重新构建，Godot 加载的是编译产物
dotnet build

# 图形界面运行
& 'E:\software\Godot_v4.7.1-stable_mono_win64\Godot_v4.7.1-stable_mono_win64.exe' --path .

# 或者用编辑器打开（推荐，能看场景树和调试器）
& 'E:\software\Godot_v4.7.1-stable_mono_win64\Godot_v4.7.1-stable_mono_win64.exe' --editor --path .
```

> ⚠️ 本机 .NET SDK 是 8/9，而 Godot 4.7.1 编辑器自带的 C# 工具链要求 SDK **10.0.8**。
> 所以编辑器里可能弹 `.NET Sdk not found` 的报错，且「构建」按钮不可用。
> **这不影响使用**：用命令行 `dotnet build` 构建，编辑器按 F5 照样能跑。
> 想彻底解决就装一个 [.NET SDK 10](https://dotnet.microsoft.com/download)。详见 [README](../README.md#环境注意本机实测务必先看)。

## 2. 操作

| 按键 | 作用 |
|---|---|
| `WASD` / 方向键 | 移动 |
| `E` | 与传送门交互（进入练习站） |
| `TAB` | 展开 / 收起练习任务面板 |
| `R` | 重开当前练习站（清掉现场，回到初始状态） |
| `ESC` | 打开 / 关闭**暂停菜单**（含音量与全屏设置，每个练习站都有） |
| `F3` | 性能面板：FPS / 帧时间 / 绘制调用 / 节点数 / 内存 |
| `空格` | 跳跃 / S01 生成方块 |
| `Shift` | 冲刺（S02） |
| `G` | S01：用 `CallGroup` 给所有方块下指令 |
| `1` `2` `3` … `5` | 通用的「选项键」。各站自己定义含义：S02 开关三个手感辅助，S03 切换子弹碰撞掩码预设，S05 开关五种相机/打击感效果 |
| 鼠标滚轮 | S05：相机缩放 |
| `J` / 鼠标左键 | 攻击（留给 S07） |

所有按键都定义在 `project.godot` 的 `[input]` 段，也就是编辑器的
**项目设置 → 输入映射**。

注意 `jump`（跳跃）和 `spawn`（生成方块）**都绑在空格上**，这是刻意的：
**动作（action）是逻辑概念，按键是物理概念，两者是多对多的关系。**
一个动作可以绑多个键（WASD 和方向键都绑在 `move_left` 上），
多个动作也可以共用一个键。想批量改按键，用
`tools/gen-inputmap.ps1` 重新生成，不要手写那一长串 `InputEventKey` 序列化。

## 3. 一个练习站由什么组成

拿 S01 当例子：

```
src/stations/s01_lifecycle/
├── s01_lifecycle.tscn     # 场景：地板、生成台等静态布景（在编辑器里能直接看到）
├── S01Lifecycle.cs        # 玩法逻辑，继承 StationBase
├── wanderer.tscn          # 被反复生成/销毁的那个对象
└── Wanderer.cs
```

配套的三块通用设施（所有站共享）：

| 位置 | 作用 |
|---|---|
| `src/stations/station_base/StationBase.cs` | 基类。自动装 HUD、统一处理 TAB/R/ESC、记录通关进度 |
| `src/ui/station_hud/station_hud.tscn` + `StationHud.cs` | 标题栏 + 任务面板 + 状态行 + 完成横幅 |
| `src/game/StationCatalog.cs` | 全部 16 站的元信息（标题、技能点、任务文本、是否已建成） |

**读代码的建议入口**：先打开 `StationCatalog.cs` 看这一站的定位 →
再看这一站的 `*.cs` 里的 `StationReady()`（玩法从这里开始）→ 最后看 HUD 大概长什么样。

## 4. 自己加一个练习站

四步，不需要动任何 UI 代码：

1. 建目录与场景：`src/stations/s09_data/s09_data.tscn`
2. 写脚本，继承 `StationBase` 并覆盖两个成员：

```csharp
public partial class S09Data : StationBase
{
    public override string StationId => "s09_data";   // 必须与目录名、场景名一致

    protected override void StationReady()
    {
        // 玩法初始化。此时 Hud 已就绪，场景里的固定子节点也已 _Ready
    }

    private void SomeGoalReached()
    {
        MarkTaskDone(0);        // 把第 1 条任务打勾
        Complete("达成了某个目标"); // 判定通关
    }
}
```

3. 在 `src/game/StationCatalog.cs` 里加一条 `StationInfo`，并把 `Implemented` 设为 `true`。
4. 运行，枢纽里会出现新传送门。

站点场景里需要墙就用 `common/util/LevelKit.cs`：

```csharp
LevelKit.CreateBorderWalls(this, new Rect2(40, 128, 1200, 560));
LevelKit.MakeRect(this, new Vector2(640, 400), new Vector2(200, 60), Colors.SlateGray);
LevelKit.MakeLabel(this, new Vector2(640, 200), "说明文字");
```

## 5. 调试手段

| 手段 | 怎么做 |
|---|---|
| 打印 | `GD.Print(...)`，看编辑器的**输出**面板。本项目里所有 `GD.Print` 都带了 `[模块名]` 前缀，方便过滤 |
| 看碰撞 | 编辑器菜单 **调试 → 可见碰撞形状**（运行后开），改碰撞层时必开 |
| 性能面板 | 游戏里按 `F3` |
| 逐帧分析 | 编辑器下方 **调试器 → 分析器**，能看出哪个函数最耗时 |
| 远程场景树 | 编辑器 **调试器 → 远程**，运行时可实时看节点树和属性 |
| 断点 | 在 VS Code / Rider 里附加到 Godot，或在编辑器里用 `GD.Print` 代替 |

## 6. 自动化验证（命令行 / headless）

没有图形界面也能跑，适合快速检查"改了代码有没有把场景改坏"。

```powershell
cd E:\Code\GameDev\Godot\dojo

# 跑 180 帧然后退出，有 ERROR/WARNING 就以退出码 1 结束
powershell -ExecutionPolicy Bypass -File .\tools\godot-run.ps1 -ProjectPath . -Frames 180

# 只跑某个练习站
powershell -ExecutionPolicy Bypass -File .\tools\godot-run.ps1 -ProjectPath . `
    -Scene res://src/stations/s01_lifecycle/s01_lifecycle.tscn

# 导入资源（新建了场景/图片后，或第一次打开工程前）
powershell -ExecutionPolicy Bypass -File .\tools\godot-run.ps1 -ProjectPath . -Import
```

**截图 / 看画面**（不需要手动操作，引擎会自动"玩"一段再录成图片）：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\godot-run.ps1 -ProjectPath . -Frames 460 `
    -WriteMovie '.logs/shots/e2e.png' `
    -UserArg '--dev-input=move_left:0.3:2.3,move_up:2.5:4.5,interact:4.8:4.9,spawn:5.4:7.4'
```

- `--dev-input=动作:按下秒数:松开秒数`，多条用逗号分隔（实现见 `src/dev/DevAutomation.cs`）。
- 输出是一串 PNG（`.logs/shots/e2e00000042.png`），外加一个 `.wav`。
- 上面这条指令的意思是：左移 2 秒 → 上移 2 秒 → 按 E → 按住空格生成方块。
- 它同时也是**自动化回归测试的雏形**：把一串固定输入喂进去，看画面和预期是否一致。

> 这两个工具脚本刻意写成**纯 ASCII**。原因：本机 shell 是 Windows PowerShell 5.1，
> 它会把「无 BOM 的 UTF-8 文件」按 GBK 解码，中文行尾的第二个字节会吃掉换行符，
> 导致下一行代码被静默吞掉。给 .ps1 写中文注释是很危险的，中文说明放在 `.md` 里。

## 7. 存档

- 位置：`%APPDATA%\Godot\app_userdata\Godot Dojo\dojo_save.json`
- 内容：已通关的练习站、最后进入的站、各站的自定义数值
- 重置进度：删掉这个文件即可
- 换存档位置：启动参数加 `-- --save-dir=D:\some\dir`
  （这也是 `SaveSystem` 里演示"把外部依赖变成可注入参数"的地方，方便测试）
